# Dungeon Veil

Versión V45 preparada para publicarse con GitHub Pages.

## Publicar
1. Crea un repositorio público llamado `Dungeon-Veil` en https://github.com/new
2. Sube `index.html` a la raíz del repositorio y confirma los cambios.
3. En Settings → Pages, selecciona `Deploy from a branch`, rama `main`, carpeta `/ (root)`, y guarda.
4. Espera a que termine la publicación. El enlace normalmente será `https://TU-USUARIO.github.io/Dungeon-Veil/`.

Este paquete contiene el archivo principal del juego. No modifica ni elimina el repositorio anterior.
